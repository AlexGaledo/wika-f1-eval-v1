Can the Wika voice speak the regional languages?

WIKA-F1, the Wika voice, read 30 held-out sentences in Tagalog and in each of six regional languages. A speech recognizer trained for each language (Meta MMS) transcribed them without seeing the text. Lower error means easier to understand. Real human recordings of the same sentences set the bar.

Character error rate, judged by Meta MMS

Each cell: character error (word error below). PER = phoneme error from a separate model. Collapses (broken or runaway audio) were zero for every system in every language. Designed = the voice description alone; Native clone = a real FLEURS speaker's voice (Cebuano and Tagalog only).

Tagalog comes from the 16 Oct test, where WIKA-F1 is itself the designed voice, so it has no separate Designed column. Its samples are classroom lines checked by Whisper, not the held-out test set.

What this does and does not show

It shows the words come out clear enough for a native-language recognizer to get them right, as often as with real speakers. That is the bar for using it as a teacher to train small dialect models, the same way the Tagalog model is being trained now.

It does not show whether it sounds native. The Wika voice is Tagalog-born, so stress, rhythm and some vowels may carry a Tagalog accent a recognizer forgives but a Cebuano or Ilocano listener would not. Native speakers need to listen before any of these ship.

The human recordings are research-licensed PLD audio, so only their scores appear here, not the audio.
